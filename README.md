## Who am I

I'm **Shikhali Jamalzade** — an offensive security researcher based in **Baku, Azerbaijan**. I specialize in web application exploitation, Active Directory attack chains, and building tools that make penetration testing faster, deeper, and harder to defend against.

My approach is simple: understand the system deeply enough to break it cleanly, document it precisely enough that the fix is undeniable, and automate everything worth repeating.

I've completed red team certification tracks through **INE**, **CyberWarFare Labs**, covering web exploitation, Active Directory pivoting, lateral movement, credential dumping, and post-exploitation — not just theory, but full attack chain execution under real lab conditions.

On the research side, I hunt bugs on **Bugcrowd**, play CTFs on **HackTheBox** and **TryHackMe**, and write about my findings on [Medium](https://alisalive.medium.com). Everything I learn goes into a tool, a writeup, or both.

> *"hack the planet. then document it properly."*

**[XSSSlayer](https://github.com/alisalive/XSSSlayer)**

Real-browser XSS scanner powered by Playwright. Bypasses WAFs through AI-generated payload mutation, executes in headless Chrome to catch DOM-based vulnerabilities that proxy-based scanners miss entirely. Built for engagements where other tools give up.

`Python` `Playwright` `WAF Bypass` `XSS`
